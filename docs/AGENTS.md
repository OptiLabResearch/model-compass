# Documentation scope

Use `docs/DEVELOPMENT.md` as the current task-routing and validation index.
`docs/PROJECT.md`, `docs/ARCHITECTURE.md`, and `docs/STATUS.md` are current
authorities for scope, design, and state. Read an active plan before changing
planned work. `docs/reports/archive/` is historical evidence, not current
policy or status; inspect it only when a report is directly relevant.

Keep guidance concise, link to canonical instructions instead of copying
command catalogs, and label historical or proposed material clearly.
