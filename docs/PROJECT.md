# Project

Model Compass is a durable, Codex-first recommendation and model-intelligence project. It combines source-specific evidence into explainable model, provider, and agent decisions while preserving provenance and uncertainty.

## Scope

- Maintain the dependency-free static comparison site and JSON deployment boundary.
- Build deterministic, auditable acquisition and normalization pipelines.
- Provide trustworthy model/provider recommendations, decision profiles, history, and change intelligence.
- Keep repository documentation, tests, reports, and generated artifacts sufficient for a new Codex session to resume from Git alone.

## Non-goals

- Operating an inference gateway or automatic production router.
- Treating absent evidence as zero or inferred identity as fact.
- Adding databases, services, frameworks, or paid data access without demonstrated need and approval.
- Scraping fragile upstream presentation layers when a reasonable documented contract exists.
