# Roadmap

1. **Phase 2 — provider and coding-agent baseline (accepted on `main`).** Preserve separate operational/provider and harness observations with deterministic recommendation primitives.
2. **Phase 3 — Endpoint Accuracy and explicit identity (accepted 2026-08-24).** PR #7 passed variant-safe identity, authoritative fail-closed joins, reproducible acquisition/artifact generation, version-safe history, live Gate D, full CI, and independent Sol review.
3. **Phase 4 — source contracts and identity coverage (next).** Audit upstream contracts and mapping coverage; prefer documented APIs/metadata over custom extraction where technically and economically reasonable.
4. **Phase 5 — richer decision profiles.** Add evidence-backed best-overall, available-to-me, and marginal-cost-aware recommendations.
5. **Phase 6 — history and alerts.** Turn comparable history into useful change intelligence and bounded alerts.
6. **Phase 7 — product integrations.** Add UI, Model Lab, routing, or preset outputs only when decision quality and a concrete user need justify them.

Later-phase details are hypotheses. Before each phase, re-check repository and upstream evidence and choose the smallest coherent implementation that advances the project objective.
